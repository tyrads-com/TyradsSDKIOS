# Installation

Add the SDK via Swift Package Manager.

In Xcode: **File → Add Package Dependencies**, enter:

```
https://github.com/tyrads-com/TyradsSDKIOS.git
```

Or add directly to `Package.swift`:

```swift
dependencies: [
    .package(url: "https://github.com/tyrads-com/TyradsSDKIOS.git", from: "4.0.0")
]
```

Then add `TyradsSDKIOS` to your target's dependencies.
